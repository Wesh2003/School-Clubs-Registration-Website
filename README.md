# Club Registration Web Application

A simple and modern web app for managing student club registrations.

## Overview
This project allows students to browse clubs, register online, and track their membership status, while administrators can manage clubs and registration requests efficiently.

## Features
- Students can view and join available clubs
- Administrators can manage clubs and registrations
- Registration status can be tracked easily
- Clean and user-friendly interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript (or React)
- Backend: Node.js / Express
- Database: MySQL or PostgreSQL
