# Club Registration Web Application

A simple web app for managing student club registrations.

## Overview
This project helps students register for clubs online and helps administrators manage registrations easily.

## Features
- Student can browse and join clubs
- Admin can manage clubs and registrations
- Registration status can be tracked
- Simple and user-friendly interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript (or React)
- Backend: Node.js / Express
- Database: MySQL or PostgreSQL

## Getting Started
1. Clone the repository
2. Install dependencies
3. Run the app locally
4. Open it in your browser
